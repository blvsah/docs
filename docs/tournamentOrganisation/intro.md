# Ausrichterhinweise

Um eine gute Übersicht über ein Projekt zu haben, lohnt es sich evtl. ein Kanban Tool zu benutzen.

Es gibt viele davon im Internet, z. B. [Trello](https://trello.com/), [Kanboard](https://kanboard.org/) (self-hosting), [projoodle](https://www.projoodle.com/de).

Eine Planung kann weiterhin unterstützt werden durch Tools wie [mitbringen.net](https://mitbringen.net), [list2go](https://list2go.io/de/).

Gerade wenn Aufgaben im Team verteilt werden, ist dadurch eine ganz gute Übersicht vorhanden.

Die folgenden Meilensteine und Tasks sind als Hilfen gedacht und müssen evtl. ergänzt/abgeändert werden, je nach Sporthallen oder Turnier Situation.
