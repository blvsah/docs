# Neues Turnier erstellen

## Öffnen

Der Badmintonturnierplaner wird per Doppelklick auf das StartIcon oder durch ein bereits vorhandene Turnierdatei geöffnet.

![winBtpIcon](./assets/images/winBtpIcon.png 'BTP Icon')

## Neu

![btpCreateNewTournament](./assets/images/btpCreateNewTournament.png 'BTP Neues Turnier erstellen')

Über das obere Menü `Turnier` - `Neu` oder der Tastenkombination <kbd>strg</kbd> + <kbd>n</kbd> wird ein neues Turnier erzeugt.

:::info

Für jedes Turnier muss eine neue Turnierdatei generiert werden. Keine alten Turnierdateien wiederverwenden und abändern!

:::

Es öffnet sich ein Dialog zum angeben eines Dateinamens.

![winCreateNewFileDialog](./assets/images/winCreateNewFileDialog.png 'BTP Dateidialog Neues Turnier')

## Dateiname

Der Dateiname sollte nach folgendem Muster angelegt werden :

*datum\_turnierart\_[region]_disziplin_altersstufen_spielort.tp*

||Beispiel|
|---|---|
|**Datum**|JahrMonatTag: 20260321|
|**Turnierart**|crlt, cmst, drlt, dmst|
|**Region** (bei Regionsturnieren)|des (Dessau), hal (Halle), md (Magdeburg)|
|**Disziplin**|e (Einzel), d (Doppel), m (Mixed)|
|**Altersstufe**|u11u13u15u17u19|

**Beispiel:** 20260321_crlt_ed_u17U19_foerderstedt.tp

Durch klicken auf `Speichern` wird die Turnierdatei erzeugt und direkt geöffnet.

:::warning

Der Dateiname wird gleich als Turniername übernommen, was es dann abzuändern gilt.

:::

Nach Erstellung des Turnieres öffnet sich direkt der Turniereigenschaftsdialog für die nächsten Schritte.
