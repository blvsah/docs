# Veröffentlichen

Turniere des Verbandes werden im Internet auf dbv.turnier.de veröffentlicht. Dadurch ist eine online Anmeldung der Teilnehmenden durch die Vereine möglich.

Über das obere Menü `Internet` - `Veröffentlichen...` das Fenster zum veröffentlichen öffnen.

:::warning

Für privat Turniere ist eine eigene Lizenz für die Tournamentsoftware zu kaufen. Wendet euch an den Verband, um die Lizenz über den Verband mit ggf. Verbandsrabatt zu beziehen.

:::

## Allgemeine Tab

![btpPublishDialog](./assets/images/btpPublishDialog.png 'BTP Veröffentlichen Allgemein')

Im Allgemeinen Tab ist anzugeben, dass:

* Flaggen
* Bundesland
* Verein
* Ranking

angezeigt werden sollen.

Die Spieler sollen nicht versteckt werden.

Es ist möglich eine Message anzugeben. Diese wird als Hinweis auf dbv.turnier.de beim Turnier angezeigt.

:::info

Die Message ist gut für kurzfristige Infos, da es beim Aufrufen des Turnieres über dbv.turnier.de an sich nicht übersehen werden kann.

:::

## Verordnung Tab

Im Verordnung Tab ist es möglich die Ausschreibung zum Turnier zu veröffentlichen. Auf dbv.turnier.de ist der Text dann unter Bestimmungen zu finden.

:::warning

Formatierungen (Fett, Kursiv etc.) im Text gehen allerdings verloren.

:::

:::info

Einen direkten Link zu den Bestimmungen kann selbst "kreiert" werden: `https://dbv.turnier.de/sport/regulations.aspx?id=<TURNIER_ID>`

Dadurch ist es möglich im DBV-JWS Kalender sehr einfach auf die Ausschreibung zu verlinken.

:::

## Online Anmeldung Tab

Bevor der Button `Veröffentlichen` das Turnier ins Internet lädt, sind im Tab `Online Anmeldung` noch wichtige Einstellungen vorzunehmen.

![btpPublishDialogOnlineEntry](./assets/images/btpPublishDialogOnlineEntry.png 'BTP Veröffentlichen Online Anmeldung')

* Online Anmeldung: **Gruppe**
* SpielerID erforderlich!
* Meldeschluss: Freitag in der Vorwoche vor dem Turnier 23:59 Uhr
* Withdrawal date: Dienstag vor dem Turnier 23:59 Uhr

Lasst den Haken bei `Double Partner required` weg, um Freimeldungen zuzulassen.

:::warning

Die Auswahlbox Online Anmeldung muss zwingend auf `Gruppe` stehen. Nur so sind bei den Vereinen die Personen hinterlegt und auswählbar die eine Spielberechtigung besitzen.

:::

Das Turnier wird in einem letzten Schritt über den Button `Veröffentlichen` auf dbv.turnier.de hochgeladen und ist dort verfügbar.
