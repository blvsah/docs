# Badminton Turnier Planer (BTP)

Eine kleine Einführung in die Turniersoftware von Visual Reality (dbv.turnier.de)

Deutschlandweit ist diese Software für die Turniere im Jugendwettkampfsystem vorgeschrieben.

Bereits durchgeführte Turniere sind in einer Übersicht unter [dbv.turnier.de](https://dbv.turnier.de/find.aspx?a=7&q=803E40C7-8793-43F8-B6FE-DCB21263B6E7) zu finden.

:::warning

Als Betriebssystem benötigt die Turniersoftware Microsoft Windows.

Über eine virtuelle Umgebung ist es durchaus auch mit anderen Betriebssystemen verwendbar. Die Stabilität für eine Turnierausrichtung muss aber selbst getestet werden.
