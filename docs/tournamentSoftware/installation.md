# Installation

## Lizenzschlüssel

Bei der Erstinstallation oder wenn der Lizenzschlüssel abgelaufen ist, fragt die Software beim Start nach einem Lizenzschlüssel. Alternativ kann eine Demoversion gestartet werden, mit eingeschränkten Möglichkeiten.

Hast du einen gültigen Lizenzschlüssel per E-Mail bekommen, speichere den Lizenzschlüssel vor den weiteren Schritten aus der E-Mail auf die Festplatte.

Wenn die Software nach dem Lizenzschlüssel fragt, wähle den Schlüssel von der Festplatte aus.

Im nach hinein kann die Lizenz über das obere Menü `Hilfe` - `Registrieren` hinterlegt werden.

![btpLicenseDialog](./assets/images/btpLicenseDialog.png 'BTP Lizenz')

:::info

Die Funktionen der Software kann auch ohne Lizenzschlüssel getestet werden. Ein Limit besteht u. a. in der Anzahl von Teilnehmenden an einem Turnier. Was zum Testen und rein finden in die Software aber kein Problem darstellen sollte.

:::

### Wechseln der Lizenz

Für private Turniere muss ein ausrichtender Verein eine eigene Lizenz benutzen. Es ist also notwendig, wenn Turniere für den Verband ausgerichtet werden, die jeweilige Lizenz zu wechseln.

Der Wechsel der Lizenz ist über das obere Menü `Hilfe` - `Registrieren` möglich.

:::warning

Damit das jeweilige Turnier auf dbv.turnier.de dem richtigen Veranstalter (Verband/Verein) zugeordnet wird, muss die Lizenz wirklich gewechselt werden. Denn die offiziellen Verbandsturniere sollen übersichtlich auf [dbv.turnier.de](https://dbv.turnier.de/find.aspx?a=7&q=803E40C7-8793-43F8-B6FE-DCB21263B6E7) zu sehen sein.

:::

## Download der Software

Die aktuellste Software wird unter https://dbv.turnier.de/product/download.aspx?id=16&s=2 zum download angeboten.

![turnierDeDownload](./assets/images/turnierDeDownload.png 'BTP Download')

Richtige Sprache (deutsch) und Sportart (Badminton) suchen und den Download Button in der Zeile benutzen.

Die Turniersoftware wird auf der Festplatte für die Installation gespeichert.

## Installation der Software

Die runter geladene Datei per Doppelklick ausführen, und den Anweisungen folgen.

![winOpenInstallMedium](./assets/images/winOpenInstallMedium.png 'BTP Installation starten')

:::info

Es ist ratsam die Software zur Nutzung durch alle Benutzer des Gerätes zu installieren.

![winInstallForAll](./assets/images/winInstallForAll.png 'BTP Installation für alle')

:::

## Update

Die Software sollte immer aktuell gehalten werden. Gerade für ein Turnier sollte die neuste Version benutzt werden.

Der BTP verfügt über eine Auto-Update Funktion auf der Übersichtsseite:

![btpAutoUpdate](./assets/images/btpAutoUpdate.png 'BTP AutoUpdate')

Die Funktion ist ebenfalls über das obere Menü `Hilfe` - `Auto-Update` erreichbar.

Den Hinweisen folgen und den Update Vorgang durchführen.

:::warning

Sollte die Auto-Update Funktion nicht funktionieren, einfach die Installation wiederholen. [Siehe `Download der Software`](#download-der-software)

:::
